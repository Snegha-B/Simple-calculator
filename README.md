# 🧮 Python Simple Calculator

A beginner Python project built using **Jupyter Notebook** that performs basic arithmetic operations and demonstrates fundamental programming concepts such as user input, conditional statements, and arithmetic operators.

---

## 📌 Project Overview

This calculator allows users to perform common mathematical operations through a simple menu-driven interface. It was created as an early Python learning project to strengthen programming logic and problem-solving skills.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🟰 Modulus
- 🔢 Menu-driven user interaction

---

## 🛠 Tech Stack

- Python
- Jupyter Notebook

## ▶️ How to Run

1. Open the project in **Jupyter Notebook**.
2. Run all cells.
3. Enter two numbers.
4. Choose the required arithmetic operation.
